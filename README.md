# Photo-Mapper

HTML app to plot GPX tracks and photos with geolocation EXIF data 
on an interactive map.

## Features
- Load and display GPX tracks on a map
- Plot photos using GPS coordinates from EXIF data
- Local photo support

## Usage
Use the live app at: https://asg49.github.io/Photo-Mapper/

## Notes
Currently supports local photos only. Google Photos integration 
is in development.
